# Diplom
## Описание проекта
### В данной работе будет тестироваться приложение Steam
### Steam - это многофункциональное приложение для геймеров которое включает в себя множество аспектов для разной аудитории. В нем собранно достаточно функций, которые позволяют пользователю не выходя из него получить нужную информацию по товару. В добавок присутствует функционал позволяющий не задействовать сторонние приложения для общения и коммуникации  и позволяющие сэкономить ресурсы ПК
